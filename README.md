# GTM Automation Workflows

Collection of workflow automation systems built using n8n and AI agents, focused on lead qualification, enrichment, and GTM operations.

---

## Overview

This repository contains a set of automation workflows designed to streamline go-to-market (GTM) processes such as:

- Lead capture and enrichment  
- Intent detection and qualification  
- Data processing and filtering  
- Automated scoring and prioritization  

---

## Projects

### LinkedIn Intent Engine
Automated pipeline that processes LinkedIn engagement data, filters relevant leads, classifies companies, and scores prospects for outreach.

**Key Features:**
- Real-time trigger from Google Sheets  
- Persona and company filtering  
- AI-powered company classification  
- Fraud exposure and persona scoring  
- Lead tiering system for prioritization  

 `./linkedin-intent-engine` 

---

## Usage

Each project folder contains:
- Exported workflow (`.json`)
- Project-specific README with setup and explanation

To use:
1. Import the workflow into your n8n instance  
2. Configure credentials (Google Sheets, APIs, etc.)  
3. Run and test with sample data
